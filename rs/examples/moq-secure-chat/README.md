# moq-secure-chat

Chat functionality built on top of the `moq-secure` library.

This package provides the chat protocol and session logic used by
[moq-secure-chat-cli](https://github.com/cathode-ray-tube/moq-secure/tree/main/rs/examples/moq-secure-chat-cli).

Build it from the repository root:

```bash
cargo build -p moq-secure-chat
```
